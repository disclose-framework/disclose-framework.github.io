01 / Discovery

One file. Any agent.

Entities publish at /.well-known/disclose. Same idea as robots.txt, but for agents instead of crawlers. No registry to join, no platform to depend on. If an agent knows the convention, it can find the file.

02 / Attestation

Named Signatories. Staked reputations.

Every signal says how it was produced: signed by a Signatory, computed from platform data, or self-reported by the merchant. Agents weight the data accordingly. The companies that already hold this data (returns platforms, logistics providers, payment processors) can stake their reputation on it. The tiers are in the spec. Signatory pilots come next.

03 / Architecture

Three scopes. One document.

Signals live at three scopes: Merchant, Offer, Item. An agent comparing one product across two sellers gets entity-level performance, SKU-level data, and item-level attributes from a single endpoint.

Premise
AI agents are becoming the layer that decides what gets bought. They can only read what is machine-readable. Today that means price, reviews, availability, and whatever merchants claim about themselves. The operational record is missing: return rates, on-time shipment, how refunds and disputes actually resolve. That data exists. Merchants, platforms, and payment processors already hold it. Agents just cannot see it.

Disclose is a schema for publishing that record at a well-known URL. Core operational signals, each one declared signatory-attested, computed, or self-reported. No scores. No badges. No verdicts. The agent reads the data and draws its own conclusions.

Starting with commerce, where the data already lives.
Proof

The policy text is the worst case. The data is what actually happens.

Every signal declares how it was produced, up front. No scores, no badges, no verdicts. Just provenance, so the agent can weight the data itself.

signatory

Signed by a Signatory with direct access to the source data. The Signatory stands behind the signal.

computed

Computed from platform or source-system data by a third party. Harder to fake than self-reported data, but no Signatory stands behind it.

self-reported

Declared by the merchant. No third-party computation, no signature. The agent weights it accordingly.

Seven signals, one endpoint, nothing to infer.

Governance
Disclose is MIT-licensed. No single company owns the spec. Not a platform, not a Signatory, not the founder.

Independent governance is still an open question. The working group exists to answer it.
